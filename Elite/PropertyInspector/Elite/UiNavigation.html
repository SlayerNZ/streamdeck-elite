Hold Mode
Hold Threshold (ms)
Hold Mode lets a button do both jobs. A tap still sends exactly the Presses count above, so menu buttons land on a precise number of steps. Keep it held past the Hold Threshold and the key stays down, moving continuously until you let go — useful for FSS tuning, galaxy map panning and camera movement.

Best left off for Select and Back, where an accidental hold would repeat-fire them. The "… On" panel and map entries cannot be held and always send a normal press.
Advanced
Condition Check
The Advanced option checks a condition before the button does anything. If the condition is not true, the button does nothing — so a step placed in a multi-action stays silent rather than firing at the wrong moment.
