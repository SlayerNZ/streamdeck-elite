Sends the keys you have bound in Elite, so it follows your own control setup. The touch strip shows bio and geo signal counts — for a body you have just resolved in the FSS (briefly), otherwise for the body you are currently at. A function bound only to a HOTAS or mouse cannot be sent; give it a keyboard binding as well.
Actions that charge while held, such as the Discovery Scan, need the key held down rather than tapped. The dial press already does this — it holds for as long as you hold the encoder. A touch has no release to wait for, so set Touch Hold to how long the key should be held (try 1000 ms for a Discovery Scan). Leave it at 0 for normal one-shot actions.

Bind held actions to a plain key, with no Shift/Ctrl/Alt modifier. Elite does not reliably accept a held modifier chord, so a Discovery Scan bound to something like Shift‑D will not charge — it will appear to do nothing at all. An unmodified key works.
Enter and Exit FSS are often bound to the same key, in which case that key is a toggle and picking either entry does the same thing. Assign it once rather than to two separate slots.
